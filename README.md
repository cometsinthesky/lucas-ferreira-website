# Lucas Ferreira Science & Physics

Portfólio digital de recursos educacionais, jogos, simulações, materiais didáticos, imagens, publicações e projetos autorais voltados ao ensino de Ciências e Física.

O site foi desenvolvido para reunir, em um único ambiente, materiais acadêmicos, recursos visuais, projetos interativos e produções educacionais autorais, com navegação contínua, layout responsivo e foco em experiência visual moderna.

## Visão geral

O **Lucas Ferreira Science & Physics** é um website em HTML, CSS e JavaScript criado para apresentar conteúdos educacionais e científicos de forma organizada, visual e acessível em diferentes dispositivos.

O projeto reúne:

- perfil acadêmico e profissional;
- livro autoral;
- jogos online;
- jogos impressos;
- simulações;
- materiais didáticos;
- imagens;
- publicações;
- contato por formulário.

## Funcionalidades do site

### 1. Navegação lateral fixa
O site possui uma barra lateral com:

- apresentação do autor;
- menu principal com âncoras internas;
- atalhos rápidos;
- links externos para GitHub, Lattes, LinkedIn e Instagram.

Essa navegação facilita o acesso rápido às seções do portfólio.

### 2. Menu superior responsivo
O menu superior complementa a navegação do site.

- **Desktop:** aparece no topo com comportamento visual mais discreto.
- **Smartphone:** funciona como menu colapsável, reduzido no topo da tela, podendo ser expandido e recolhido com toque.

### 3. Seções organizadas por categorias
O conteúdo do site está dividido em seções temáticas, como:

- **Profile**
- **Livro**
- **Jogos Online**
- **Jogos Impressos**
- **Simulações**
- **Materiais Didáticos**
- **Imagens**
- **Publicações**
- **Contato e Email**

### 4. Cards de conteúdo
Cada material é apresentado em formato de card, com:

- imagem de capa;
- categoria e palavras-chave;
- título;
- breve descrição;
- botões de ação;
- preview visual do material.

### 5. Carrossel de previews
Diversos cards possuem um bloco chamado **Preview do material**, com:

- navegação entre imagens;
- pontos indicadores;
- alternância de slides;
- visualização integrada ao card.

### 6. Lightbox para imagens
As imagens podem ser abertas em destaque com efeito de visualização ampliada, permitindo uma experiência mais imersiva para o visitante.

### 7. Destaque automático das seções ativas
A navegação lateral acompanha a rolagem da página e destaca automaticamente a seção atualmente visível.

### 8. Animações de entrada
Os elementos do site surgem gradualmente durante a rolagem, criando uma navegação mais fluida e moderna.

### 9. Formulário de contato com EmailJS
O site possui formulário funcional para envio de mensagens, com integração ao **EmailJS**, permitindo:

- envio de mensagem para o responsável pelo site;
- resposta automática para o visitante;
- feedback visual de sucesso ou erro no envio.

### 10. Layout responsivo
O site foi planejado para funcionar em:

- desktop;
- tablet;
- smartphone.

A estrutura se adapta conforme o tamanho da tela, reorganizando navegação, cards, previews e menus.

## Como utilizar o site

### Navegação
1. Abra o site no navegador.
2. Use o menu lateral ou o menu superior para acessar uma seção.
3. Role a página para explorar os conteúdos.
4. Clique nos botões dos cards para:
   - abrir jogos;
   - acessar repositórios;
   - baixar materiais;
   - visualizar publicações;
   - abrir links externos.

### Preview dos materiais
1. Em cards com preview, navegue entre as imagens.
2. Explore as capturas de tela e materiais visuais antes de abrir o conteúdo completo.

### Imagens ampliadas
1. Clique em uma imagem habilitada para visualização.
2. A imagem será exibida em destaque.
3. Clique novamente ou pressione `Esc` para fechar.

### Contato
1. Vá até a seção **Contato e Email**.
2. Preencha nome, email, assunto e mensagem.
3. Clique em **Enviar**.
4. Aguarde a confirmação de sucesso ou erro.
